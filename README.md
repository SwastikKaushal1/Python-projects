Welcome to my Python school projects repository! 🎉

This repository contains a collection of basic Python programs that I developed as part of my school assignments. These projects cover fundamental concepts of Python, including data types, control structures, mathematical calculations, and more. Whether you're a beginner or looking to refresh your knowledge, these small programs can serve as great learning tools.

### Projects Included
- **Age Calculator**: A program to calculate age based on the birthdate.
- **Area of Circle and Circumference**: A program to calculate the area and circumference of a circle given its radius.
- **Area of Triangle**: A program to calculate the area of a triangle.
- **Height Converter (cm to ft)**: Converts height from centimeters to feet.
- **Percentage of Marks**: Calculates the percentage of marks obtained.
- **Salary Calculator**: Computes salary after deductions.
- **Simple Interest Calculator**: A simple program to calculate interest on a given amount.
- **Time Converter**: Converts time between different units.

### Skills Covered:
- Basic Python syntax and structure.
- Functions and variables.
- Control structures like if-else and loops.
- Working with math operations in Python.

### Objective:
The goal of this repository is to build a solid foundation in Python programming while working on practical examples and solving problems. These projects are designed for beginners and will help strengthen your coding skills.
Feel free to update or expand it as you add more projects to this repository! This brief overview introduces the purpose of the repository, outlines the projects it contains, and provides some context for users exploring it.
